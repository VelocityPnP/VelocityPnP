# Security

## Supported versions

Only the current `main` branch is supported.

## Report a vulnerability

Use GitHub private vulnerability reporting. Do not open a public issue for a
suspected vulnerability.

Include the affected revision, impact, reproduction steps, and a minimal proof
of concept if possible. Reports that contain only automated scanner output,
without a reproducible impact, can be closed without further review.

This project has no bug bounty program. Reports are reviewed on a best-effort
basis. No response time is guaranteed.
